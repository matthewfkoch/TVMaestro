# TVMaestro companion

TVMaestro is a phone and tablet guide for a TVMaestro server on your home network.

1. Install the companion app.
2. Enter the server address and port (default **6790**), or open **View sample guide** to browse a local sample without a server.
3. Use the guide to start and stop playback on a paired television. Playback stays on the television apps. The phone and tablet do not play the streams.

In the guide, **Settings → Change server** returns to the connect screen.

The companion does not collect personal data. It stores only the server host, port, and scheme on the device. There is no account system.

Source and issues: https://github.com/matthewfkoch/TVMaestro

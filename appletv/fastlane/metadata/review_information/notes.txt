There is no account. On the first screen, select Preview.

That plays four sample pictures, with sound on one. The remote changes the television volume. Menu stops playback.

The guide is separate software on the home network and is not required to review playback. The guide can send up to nine streams to this same player.

The app allows local HTTP only so that server can send video. It does not load remote web pages.

The app stores only a port, an optional auth token, and guide pairing flags on the device. It does not collect personal data.

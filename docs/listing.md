# TVMaestro

TVMaestro plays video from the TVMaestro guide on your home network.

Add this device in the guide. The guide starts and stops playback and can show up to nine streams at once. Volume and mute in the guide change the stream that has sound. The remote still controls the television.

The app does not include its own lineup. Leave it open, or pair it once in the guide so playback can start when the app is not in front. The device has to be awake.
